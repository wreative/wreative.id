# Brand Color Update Design

## Goal

Align `DESIGN.md` with Wreative's current brand palette and the supplied Google Labs guidebook, keeping all color guidance consistent throughout the document.

## Palette and roles

- `#3A455C`: primary brand color for primary actions and strong emphasis.
- `#2F3542`: dark secondary color for dark surfaces and supporting contrast.
- `#DFE4EA`: light neutral for light surfaces and canvas.
- `#EB5250`: accent color for restrained brand emphasis.

## Scope

Update the color tokens, light and dark theme values, palette descriptions, component color examples, and quick-reference/agent guidance in `DESIGN.md`. Cite `https://wreative.com/` and `https://labs.google.com/u/0/pomelli/brand_book/asunQCvdRNM5fhZelQg4Um` as references. Preserve typography, spacing, geometry, and other non-color guidance. Transparency values may remain where they describe effects rather than brand colors.

## Validation

Review the full document for obsolete palette values and contradictory color guidance. No application behavior or runtime code changes are in scope.
