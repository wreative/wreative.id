# PWA and Icon Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Wreative's current icons and installable PWA metadata available consistently across all five pages.

**Architecture:** Add one `PwaHead.astro` component to own shared icon links, app metadata, theme color, manifest link, and service-worker registration. Include it in every page head while keeping page-specific SEO metadata local; align the hand-authored manifest with the current site theme and reuse the existing brand artwork.

**Tech Stack:** Astro 7, static HTML output, JSON Web App Manifest, Node.js built-in test runner.

---

## File structure

- Create `tests/pwa-icons.test.mjs` to assert generated HTML and manifest/resource consistency.
- Create `src/components/PwaHead.astro` as the single source of shared PWA and icon metadata.
- Modify `src/pages/index.astro`, `src/pages/jasa-pembuatan-website.astro`, `src/pages/jasa-pembuatan-aplikasi.astro`, `src/pages/contact.astro`, and `src/pages/404.astro` to include the component and remove duplicated theme metadata.
- Modify `public/manifest.json` to align its colors and shortcut icon resources.

## Task 1: Add failing production-output tests

**Files:**
- Create: `tests/pwa-icons.test.mjs`

- [ ] **Step 1: Add tests for page metadata and manifest assets**

Create `tests/pwa-icons.test.mjs` with:

```js
import assert from 'node:assert/strict'
import { existsSync, readFileSync } from 'node:fs'
import test from 'node:test'

const distPath = new URL('../dist/', import.meta.url)
const routes = [
  'index.html',
  'contact/index.html',
  'jasa-pembuatan-website/index.html',
  'jasa-pembuatan-aplikasi/index.html',
  '404.html',
]

test('all public routes declare shared icons and PWA metadata', () => {
  for (const route of routes) {
    const html = readFileSync(new URL(route, distPath), 'utf8')

    assert.match(html, /<link rel="icon" type="image\/x-icon" href="\/icons\/favicon\.ico"/, route)
    assert.match(html, /<link rel="icon" type="image\/png" sizes="32x32" href="\/icons\/favicon-32x32\.png"/, route)
    assert.match(html, /<link rel="icon" type="image\/png" sizes="16x16" href="\/icons\/favicon-16x16\.png"/, route)
    assert.match(html, /<link rel="apple-touch-icon" sizes="180x180" href="\/icons\/apple-touch-icon\.png"/, route)
    assert.match(html, /<link rel="manifest" href="\/manifest\.json"/, route)
    assert.match(html, /<meta name="theme-color" content="#DFE4EA"/, route)
    assert.match(html, /\/registerSW\.js/, route)
  }
})

test('manifest icons and shortcuts resolve to emitted assets', () => {
  const manifest = JSON.parse(readFileSync(new URL('manifest.json', distPath), 'utf8'))
  const referencedIcons = [
    ...manifest.icons,
    ...manifest.shortcuts.flatMap((shortcut) => shortcut.icons ?? []),
  ]

  assert.equal(manifest.theme_color, '#DFE4EA')
  assert.equal(manifest.background_color, '#DFE4EA')

  for (const icon of referencedIcons) {
    assert.ok(existsSync(new URL(icon.src.replace(/^\//, ''), distPath)), icon.src)
  }

  assert.ok(existsSync(new URL('sw.js', distPath)))
  assert.ok(existsSync(new URL('registerSW.js', distPath)))
})

test('shortcut icons use the 192px PNG asset', () => {
  const manifest = JSON.parse(readFileSync(new URL('manifest.json', distPath), 'utf8'))
  const shortcuts = manifest.shortcuts.flatMap((shortcut) => shortcut.icons ?? [])

  assert.ok(shortcuts.length > 0)
  assert.ok(shortcuts.every((icon) => icon.src === '/icons/favicon-192x192.png'))
})
```

- [ ] **Step 2: Run the tests against the current production build**

Run:

```bash
npm run build && node --test tests/pwa-icons.test.mjs
```

Expected: build succeeds; tests fail because the four non-homepage routes omit shared PWA metadata, and the manifest still has dark colors and ICO shortcut icons.

## Task 2: Centralize the shared head metadata

**Files:**
- Create: `src/components/PwaHead.astro`

- [ ] **Step 1: Add the reusable PWA head component**

Create `src/components/PwaHead.astro`:

```astro
---
const themeColor = '#DFE4EA'
---

<link rel="icon" type="image/x-icon" href="/icons/favicon.ico" />
<link rel="icon" type="image/png" sizes="32x32" href="/icons/favicon-32x32.png" />
<link rel="icon" type="image/png" sizes="16x16" href="/icons/favicon-16x16.png" />
<link rel="apple-touch-icon" sizes="180x180" href="/icons/apple-touch-icon.png" />
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content={themeColor} />
<meta name="mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="apple-mobile-web-app-title" content="Wreative" />
<meta name="application-name" content="Wreative" />
<meta name="msapplication-TileColor" content={themeColor} />
<script is:inline src="/registerSW.js"></script>
```

- [ ] **Step 2: Add the component to every page**

In each page's frontmatter, import:

```astro
import PwaHead from '../components/PwaHead.astro'
```

Then put `<PwaHead />` inside its `<head>` after the charset and viewport declarations. In `src/pages/index.astro`, remove the existing favicon links, manifest link, PWA metadata block, and registration script so each shared tag appears once. In the four other pages, remove their existing standalone `theme-color` tag.

- [ ] **Step 3: Confirm all pages use the component**

Run:

```bash
rg -n 'PwaHead|theme-color|registerSW|rel="manifest"|rel="icon"|apple-touch-icon' src/pages src/components/PwaHead.astro
```

Expected: each of the five pages imports and renders `PwaHead`; shared links and PWA metadata are defined only in `src/components/PwaHead.astro`.
