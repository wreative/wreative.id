# Custom 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a branded Indonesian-language Astro 404 page that helps visitors return to Wreative's homepage or services section.

**Architecture:** Create `src/pages/404.astro` as a standalone Astro page. Reuse the global stylesheet and existing `Button.astro` component, while avoiding the homepage header and footer because their section-only links do not work as useful navigation from an unknown URL.

**Tech Stack:** Astro 7, Tailwind CSS 4 utilities, existing project CSS and Button component.

---

### Task 1: Add the static 404 page

**Files:**
- Create: `src/pages/404.astro`

- [x] **Step 1: Create the 404 page shell**

Add document metadata with Indonesian language, responsive viewport, a 404-specific title, and `noindex, nofollow`; import `../index.css` and `../components/Button.astro`.

- [x] **Step 2: Build the page content**

Render a Wreative wordmark linking to `/`, a visible 404 status, a short Indonesian explanation, a primary home link, and a secondary services link to `/#services`. Keep links keyboard accessible and use responsive layout utilities.

- [x] **Step 3: Add restrained page-specific decoration**

Use the existing slate/coral identity with inline Astro `<style>` rules for a lightweight CSS-only 404 illustration. Include a reduced-motion-safe experience by avoiding animated decoration.

- [x] **Step 4: Validate the generated output**

Run `pnpm build`.

Expected: Astro checks pass and the build emits `dist/404.html`.

- [x] **Step 5: Check required output**

Run:

```bash
grep -E '404|Kembali ke Beranda|Lihat Layanan|noindex' dist/404.html
```

Expected: generated HTML contains the status, both navigation actions, and robots directive.
